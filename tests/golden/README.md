# 세특 점검 골든셋 (seteuk_cases.jsonl)

명백한 위반보다 **애매하고 경계에 있는 문장**을 중심으로 점검 파이프라인(규칙 + 문체 점검 + Gemini)의 정확도를 재는 평가용 데이터입니다.
문장은 모두 합성했습니다. 실존 학생·학교·교사의 이름은 쓰지 않았고, 학교명·축제명·기관명·대학명·강사명은 가상의 이름입니다.
**최종 판단은 교사가 합니다.** 라벨은 참고용 기대값이며, 근거와 불확실성은 케이스마다 `rationale`에 적었습니다.

## 구성 (90건)

| difficulty | 건수 | 성격 |
|---|---|---|
| blatant | 10 | 명시적 금지어·명칭이 그대로 드러난 문장 (맞춤법 1건 포함) |
| clean | 25 | 위반처럼 보이지만 규정상 가능한 문장(교육청·교육부 기관명, 도서명 속 상호·대학명, 소논문 가능 과목, PAPS 1등급, 외국인 성명 영문, 가운뎃점, 보조 용언 붙여 쓰기 등)과 평범한 문장 |
| subtle | 30 | 금지 내용을 우회해 쓴 문장(대회를 '행사'로 바꿔 씀, 자격 취득을 우회 서술, 'OO대' 줄임, 탐구보고서 편법 등)과 맞춤법·서식 오류 9건 |
| ambiguous | 25 | 규정이 판단을 주지 않거나 출처끼리 엇갈리는 문장(S5의 'AI' 단어, 공문 안내 행사, 윤리문제 탐구 누락 등) |

label_basis 분포: official 53 / inferred 29 / school_decides 8.
맞춤법·띄어쓰기·서식·문장부호·영문표기 관련 케이스는 약 21건입니다.

## 스키마 (한 줄에 한 케이스)

| 필드 | 값 |
|---|---|
| `id` | `B..`(blatant)·`C..`(clean)·`S..`(subtle)·`A..`(ambiguous) |
| `text` | 1-3문장 세특체 개조식 |
| `subject` | 과목명 (소논문 가능 과목 예외 판단에 사용) |
| `expected_verdict` | `기재 불가` / `확인 필요` / `기재 가능` |
| `expected_categories` | 범주 목록. 기재 가능이면 `["없음"]` |
| `difficulty` | `blatant` / `subtle` / `ambiguous` / `clean` |
| `label_basis` | `official`(명문 근거) / `inferred`(명문을 해석해 추정) / `school_decides`(규정이 판단을 학교에 맡기거나 출처가 엇갈림) |
| `rationale` | 라벨의 근거 조항, 애매한 이유, 예외 조건 |
| `source` | 조사 보고서의 출처 태그 (아래 참고) |

### 라벨 규칙
- 맞춤법·서식 오류는 내용상 기재 가능하더라도 수정이 필요하므로 `확인 필요`로 통일했습니다(앱 리포트의 '수정 필요'에 해당).
- 물결표(`~`, 변형 `∼〜～` 포함)는 문장 부호 제17항상 범위 표기로 쓸 수 있지만, 현장 지침과 spec(2026-11-24 §2.4)에 따라 경고 대상으로 두고 정답 표기는 `-`로 했습니다. 그래서 `inferred`입니다.
- `school_decides` 케이스의 기대 판정은 항상 `확인 필요`입니다.

### 출처 태그
근거는 조사 보고서(2026 기재요령·훈령 제555호·한글 맞춤법·문장 부호)와 `docs/superpowers/specs/*.md`로 한정했습니다.
- `S1 p.N`: 2026학년도 기재요령(고등) **PDF 쪽번호**입니다. 인쇄 쪽번호는 6을 빼면 됩니다. 예를 들어 p.24-25는 인쇄 p.18-19이고, p.155는 인쇄 p.149입니다(`core/rulebook.py`는 인쇄 쪽을 씁니다).
- `S2 sN`: 2026 개정사항 PPT 슬라이드 번호입니다.
- `S3`은 훈령 제555호, `S5`는 포털 Q&A(2025-12-17), `S10 제N항`은 한글 맞춤법, `S11`은 국립국어원 답변 요지, `S12 제N항`은 문장 부호입니다.
- '며칠', '됐' 케이스(B10, S29)는 표준 표기 자체는 분명합니다. 다만 보고서에 해당 조항 번호가 없어 조항 번호 없이 S10과 spec을 출처로 적었습니다.

## 평가 하니스

```
# 스키마 검증만 (id 중복, 필수 필드, 허용값, 범주-판정 정합성)
python scripts/eval_golden.py --validate-only

# 오프라인 평가 (API 호출 없음)
python scripts/eval_golden.py --out result.json
python scripts/eval_golden.py --difficulty subtle --difficulty ambiguous --seed 7 --limit 20

# Gemini 심사 반영 (비용 발생, 명시적으로 지정할 때만)
python scripts/eval_golden.py --llm --limit 10
```

- **오프라인**: `rule_based_filter`(+ `core.rulebook.apply_exceptions`를 import할 수 있으면 예외 반영)와 `style_check`를 씁니다. Gemini 없이는 `기재 불가`를 확정할 수 없어서 예측값은 `확인 필요`와 `기재 가능` 두 가지뿐입니다. 그래서 다음 지표를 함께 봐야 합니다.
  - `flag` 정확도·이진 지표: 기재 불가와 확인 필요를 양성으로 묶어 계산합니다.
  - 내용 규칙 이진 지표: 기재금지 내용 범주가 있는지와 RULE_PATTERNS가 매치했는지를 비교합니다.
  - 형식 이진 지표: 맞춤법·서식 범주가 있는지와 style_check 형식 경고가 나왔는지를 비교합니다. 상투 표현과 어미 반복 경고는 판정에서 뺍니다.
- **`--llm`**: `analyze_with_gemini(text, major="", api_key)`의 결과를 판정으로 바꿉니다(위반은 기재 불가, 주의는 확인 필요). 검출이 없으면 오프라인 판정을 그대로 씁니다. API 키는 `.streamlit/secrets.toml`의 `GEMINI_API_KEY`에서 읽고 출력·파일에 남기지 않습니다. 오류 메시지에서도 키를 가립니다.
- 출력 항목: 난이도별·라벨근거별 정확도, 3×3 혼동행렬(기대×예측), 불일치 목록(id·문장·기대·예측·rationale). `--out`을 주면 JSON으로도 저장합니다.

## 홀드아웃 (holdout_cases.jsonl, 30건)

규칙을 고치다 보면 위 90건에만 맞춰질 수 있습니다. 그래서 규칙 개선에 쓰지 않는 **독립 평가용** 30건을 따로 둡니다. 규칙이나 프롬프트를 고칠 때 이 파일의 문장을 보고 맞추지 마세요. 개선 전후 지표 비교에만 씁니다.

- 스키마·라벨 규칙·출처 태그는 위와 같습니다. id는 `H01`-`H30`입니다.
- 기존 90건의 문장과 표현은 재사용하지 않았습니다. 금지 범주는 같아도 어휘와 문형을 바꿨습니다. 예를 들어 대회는 '챌린지', 교외상은 '감사패', 장학은 '학비 지원', 출간은 '인세', 특허는 '특허를 받아', 대학명은 'OO공대', 강사는 '작가님'으로 썼습니다.
- 이름은 모두 가상입니다(새솔공대, 푸른물결해양재단, 윤가온, 물빛한마당 등).

| 묶음 | 건수 | difficulty |
|---|---|---|
| 명백한 위반 (JLPT, K-MOOC, 방과후학교) | 3 | blatant |
| 위반처럼 보이지만 가능 (교육지원청, TV·PPT, 수상(水上) 식물, 특허 제도 토론, 수학과제 탐구, 부모 직업 통계, 1990년대) | 7 | clean |
| 우회·암시 내용 위반 | 12 | subtle |
| 애매 (교습소, 고유 행사명, 해외 학교 화상 교류, 지역 대학 멘토) | 4 | ambiguous |
| 맞춤법·띄어쓰기·서식 (금새, '-였다' 종결, 원문자 번호, '것' 붙임) | 4 | subtle |

label_basis 분포: official 21 / inferred 8 / school_decides 1.

## 한계
- 문장이 모두 합성이라 실제 세특의 분포나 문체와 다를 수 있습니다.
- 라벨은 보고서에 정리된 규정을 해석한 것입니다. 교육청·학교 단위의 해석이나 2027 기재요령(아직 미확인)에 따라 달라질 수 있습니다. `inferred`와 `school_decides` 케이스는 정답이라기보다 '교사 확인이 필요한 사례'로 읽어 주세요.
- 출처 간 불일치가 있습니다. 예를 들어 소논문 가능 과목에서 윤리문제 탐구는 p.124에는 있고 p.155에는 빠져 있습니다. 이런 경우는 `school_decides`로 표시했습니다.
