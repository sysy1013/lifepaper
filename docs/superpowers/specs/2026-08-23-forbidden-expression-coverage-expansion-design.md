# 기재금지표현 감지 2차 확장 설계

날짜: 2026-08-23 / 상태: 승인됨

## 목적

2026-08-22 1차 엄격화(`2026-08-22-strict-review-subject-split-design.md`)에서
다루지 못한 기재요령 "가~파" 8개 세부 항목 중 남은 빈틈을 규칙 기반으로 메운다.
정규식으로 신뢰성 있게 잡을 수 없는 항목(부모 직업 암시, 강사명, 학교 별칭 등
고유명사·문맥 의존)은 그대로 Gemini LLM 판단에 맡긴다.

## 근거 문서 대조 (기재요령 p.18-19, p.78)

기존 RULE_PATTERNS가 놓치고 있던 것:
- **다항 (교외상)**: "표창장·감사장·공로상 등도 기재 불가"라고 명시되어 있으나
  현재 패턴은 "경시대회/올림피아드/공모전" 류만 잡음 — 상장 명칭 자체는 미탐.
- **라항 (인증시험)**: 공인어학시험(TOEIC 등)만 잡고 있고, "교내·외 인증시험"이라는
  더 넓은 범주(한자능력검정시험, 매경TEST, TESAT, KBS한국어능력시험 등)는 미탐.
- **파항 (자격증)**: 현재 목록이 6개뿐이라 실제 학생부에 자주 등장하는 자격증
  다수를 놓침.
- **세특 9번 기준 (연구보고서/소논문)**: "소논문"이라는 단어가 직접 등장하지 않고
  "제목 + 참여인원 + 소요시간"만 구체적으로 서술해도 위반인데, 현재 LLM 프롬프트가
  이를 명시적으로 짚어주지 않아 놓칠 수 있음.
- **청소년단체 활동** (기재요령 p.78): "학교교육계획에 따른 정규교육과정 이외의
  청소년단체 활동은 단체명 및 특기사항 모두 기재하지 않음" — 보이스카우트,
  걸스카우트, RCY(청소년적십자), 우주소년단, 해양소년단 등 구체적 단체명이
  전혀 커버되지 않고 있음. (사용자가 "부족하면 더 생각해서 진행"이라 위임한
  범위에서 추가 — 기재요령에 명시적으로 근거가 있는 항목만 추가함.)

## 설계

`core/rules.py`의 `RULE_PATTERNS`에 5개 튜플을 추가한다 (기존과 동일한
`(regex, reason, basis)` 형태, `severity: "주의"`로 병합되는 기존 동작 그대로):

1. 교외상 문서명: `표창장|감사장|공로상`
2. 인증시험: `인증시험` 일반 키워드 + `한자능력검정시험|매경TEST|TESAT|KBS한국어능력시험`
3. 자격증 확장: 기존 목록에 `정보처리기능사|MOS|컴퓨터그래픽스운용기능사` 추가
4. 청소년단체: `보이스카우트|걸스카우트|RCY|청소년적십자|우주소년단|해양소년단`
5. (opus 재량) 위 4개를 구현하면서 오탐 위험이 낮고 명확히 근거 있는 유사 항목을
   추가로 발견하면 포함 — 단, 새 카테고리를 만들 때마다 반드시 기재요령 원문
   근거(페이지/문구)를 주석으로 남길 것.

`core/gemini.py`의 `SYSTEM_PROMPT` 9번 기준 문구를 다음 취지로 보강한다:
"'소논문'이라는 단어가 없어도 특정 연구/탐구 활동의 제목, 참여 인원 수,
소요 시간을 구체적으로 명시하면 위반으로 판단하라"는 지시를 추가.

기존 함수 시그니처는 변경하지 않는다 — 패턴/프롬프트 내용만 확장.

## 검증

1. `tests/test_rules.py`에 5개 카테고리 각각 최소 1개 긍정 케이스(검출됨) +
   기존 `_STRICT_NEGATIVE_TEXTS`류 문장으로 오탐 없음 확인.
2. `python -m pytest -q` 전체 그린 확인 (현재 기준선 204 passed).
3. 실 배포 사이트(lifepaper.streamlit.app)에서 새 카테고리가 걸리는 실제
   문장으로 수동 스모크 테스트 — 기존 검증 흐름과 동일하게 브라우저로 확인.
